🚀 PARTIE 1 : PROCÉDURE DE DÉPLOIEMENT CLÉ-EN-MAIN SUR NETLIFY

Le projet est 100% pré-configuré pour un déploiement instantané sur Netlify grâce aux fichiers netlify.toml et public/_redirects.

📦 Méthode 1 : Déploiement Manuel Instantané (Netlify Drop) — En 2 minutes

  1. Exécutez la commande suivante à la racine du projet pour générer le build :
    npm run build
  2. Connectez-vous sur https://app.netlify.com/.
  3. Glissez-déposez le dossier dist/ dans la zone "Drag and drop your site output folder here".
  4. Le site est immédiatement en ligne avec HTTPS SSL gratuit !

🔄 Méthode 2 : Déploiement Automatique via GitHub / GitLab

  1. Poussez votre code sur GitHub :
    git add .
    git commit -m "Déploiement ISAC LMS E-Learning"
    git push origin main
  2. Sur Netlify, cliquez sur "Add new site" > "Import an existing project".
  3. Sélectionnez votre dépôt GitHub. Netlify détecte automatiquement :
    • Build Command : npm run build
    • Publish Directory : dist
  4. Cliquez sur "Deploy Site". Chaque future modification sur GitHub mettra à jour le site automatiquement !

🎓 PARTIE 2 : GUIDE D'UTILISATION DES ESPACES DE LA PLATEFORME

1. 🎓 ESPACE ÉTUDIANT

  • Inscriptions L'étudiant sélectionne sa filière d'études (ex: Génie Informatique, Comptabilité & Gestion, Transit & Douane), clique sur "S'inscrire" et remplit le formulaire de déclaration de versement.
  • Paiement Mobile Money Saisie obligatoire du Numéro de Téléphone Mobile Money (+224) et référence de transaction.
  • Droits Pédagogiques Après validation par l'Admin, l'étudiant débloque l'accès aux cours vidéo HD, quiz QCM, supports PDF/Word, au macaron de son Formateur Référent Affecté et à ses Diplômes Officiels (CQP, DQP, CAP, ATTESTATION).

2. 👨‍🏫 ESPACE FORMATEUR (Accrédité & Sécurisé)

  • Connexion Cliquez sur "Espace Formateur" > Cliquez sur "⚡ Connexion Rapide Formateur Référent" (ou dr.barry@isac-mls.com / mdp: formateur123).
  • Publication Tout Format Cliquez sur le bouton "+ Publier un Fichier / Support (Tout Format)" pour transmettre des fichiers PDF, Word, Excel, PowerPoint, MP4, MP3 audio ou archives ZIP aux étudiants de votre filière.
  • Temps Réel Les fichiers publiés apparaissent immédiatement dans le lecteur de cours de vos étudiants.
  • Forum & Live Échangez en direct sur le forum de discussion et organisez des visio-conférences interactives.

3. 🏛️ ESPACE ADMINISTRATION

  • Validation Admin Visualisation du tableau des déclarations avec téléphone (+224), photo du reçu et validation 1-clic.
  • Diplômes Officiels Génération et transfert direct des diplômes visés par le Ministère (MENA-ETFP/METFP) dans l'Espace Étudiant.
  • Formateurs Affectation des formateurs certifiés aux filières d'études.

4. 💼 ESPACE CADRES & EXECUTIVE SUITE

  • Coffre-Fort Consultation confidentielle des bilans financiers GNF et procès-verbaux de la Direction.
